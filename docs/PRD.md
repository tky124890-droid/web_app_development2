# 任務管理系統 PRD

## 1. 專案概述
- **背景與動機**：為了有效管理個人任務與時間，需要一個能清楚記錄、追蹤並分析任務完成進度的專屬系統。
- **目標用戶**：個人（我）
- **核心價值主張**：提供簡單直覺的介面，結合優先級、標籤、截止日期與進度圖表，幫助使用者高效掌握任務狀態。

## 2. 功能需求
1. **任務基本操作 (新增、編輯、刪除、標記完成)**
   - 作為使用者，我希望可以新增、編輯、刪除任務，並能將任務標記為完成，以便清楚追蹤我的待辦事項。
2. **任務優先級與標籤**
   - 作為使用者，我希望可以為任務設定優先級（如：高、中、低）與標籤分類，以便我根據重要性與專案類別來安排工作。
3. **截止日期與提醒**
   - 作為使用者，我希望可以設定任務的截止日期，以便掌控時程並在期限內完成工作。
4. **關鍵字搜尋與過濾**
   - 作為使用者，我希望可以透過關鍵字搜尋任務名稱，或透過標籤、狀態過濾任務，以便快速找到特定的待辦事項。
5. **進度統計圖表**
   - 作為使用者，我希望可以看到進度統計圖表，以便了解我完成任務的狀況與個人生產力效率。

## 3. 非功能需求
- **技術限制**：使用 Flask + Jinja2 + SQLite 作為基礎技術棧。
- **效能與安全考量**：系統需具備基本的輸入驗證以防範 SQL Injection 與 XSS 攻擊。系統在個人環境下運行需順暢，頁面載入時間與操作回應應盡量小於 1 秒。

## 4. MVP 範圍
- **Must Have (必須有):**
  - 任務的新增、編輯、刪除
  - 標記任務完成狀態
  - 任務截止日期設定
- **Should Have (應該有):**
  - 任務優先級與標籤設定
  - 關鍵字搜尋與基礎過濾
- **Nice to Have (可以有):**
  - 進度統計圖表與分析
